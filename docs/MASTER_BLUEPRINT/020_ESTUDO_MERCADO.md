# Objetivo

Antes de desenvolver qualquer funcionalidade do RPG-OS iremos estudar os melhores softwares do mundo.

Não para copiar.

Mas para compreender:

- O que fazem bem.
- O que fazem mal.
- O que falta.
- O que pode ser melhorado.

Cada software será analisado tecnicamente.

No final criaremos o melhor sistema possível.
