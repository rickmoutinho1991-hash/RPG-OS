# RPG-OS

# IMPLEMENTAÇÃO

---

Hoje termina a fase de arquitetura.

A partir deste momento começa o desenvolvimento.

Todos os módulos serão desenvolvidos sobre a arquitetura previamente definida.

Nunca será desenvolvido código sem planeamento.

Nunca será criada uma funcionalidade fora do Roadmap.

Cada módulo deverá cumprir os princípios definidos no RPG Book.

A prioridade passa a ser:

Qualidade.

Escalabilidade.

Segurança.

Performance.

Simplicidade.
