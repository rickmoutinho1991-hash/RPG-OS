# RPG-OS — Sistema Global de Permissões

## Filosofia

Nenhum utilizador possui acesso total.

Todas as permissões são configuráveis.

Tudo funciona por Roles.

# Regra

Toda ação deverá possuir uma permissão.

Nunca existirão permissões implícitas.

Tudo será registado em auditoria.

---

# Objetivo

Permitir que qualquer empresa configure exatamente quem pode fazer o quê dentro do RPG-OS.
