# RPG-OS — Módulos da Plataforma

## Filosofia

Cada módulo funciona sozinho.

Todos comunicam entre si.

Todos utilizam a mesma autenticação.

Todos utilizam a mesma base de dados.

Nenhum módulo pode duplicar funcionalidades.
