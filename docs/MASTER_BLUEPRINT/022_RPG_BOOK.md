# RPG-OS BOOK

# Constituição do Projeto

---

# Porque existe o RPG-OS

O RPG-OS nasceu para resolver um problema simples.

As empresas utilizam dezenas de aplicações diferentes.

Cada aplicação resolve apenas uma pequena parte do problema.

Isso gera:

• perda de tempo

• duplicação de trabalho

• erros

• custos elevados

• falta de comunicação

• falta de controlo

O RPG-OS pretende unificar tudo.

---

# O que nunca seremos

Nunca seremos apenas um ERP.

Nunca seremos apenas um CRM.

Nunca seremos apenas uma aplicação de orçamentos.

Nunca seremos apenas um Marketplace.

Nunca seremos apenas Inteligência Artificial.

---

# O que queremos ser

O Sistema Operativo Inteligente das Empresas.

Uma plataforma única.

Modular.

Escalável.

Segura.

Bonita.

Inteligente.

Simples.

---

# Como tomamos decisões

Antes de desenvolver qualquer funcionalidade fazemos sempre quatro perguntas.

1.

Resolve um problema real?

2.

É suficientemente simples?

3.

Pode ser utilizada por qualquer pessoa?

4.

Será útil daqui a 10 anos?

Se alguma resposta for "não"

A funcionalidade deverá ser redesenhada.

# Inteligência Artificial

A IA ajuda.

Nunca toma decisões legais.

Nunca toma decisões financeiras.

Nunca assina contratos.

Nunca elimina informação crítica.

---

# Segurança

Tudo é registado.

Tudo é auditável.

# Objetivo Final
