# RPG OS MAP

## O RPG OS é composto por 5 grandes pilares.

# 1. CORE

É o coração do sistema.

Responsável por:

- Entidades
- Utilizadores
- Empresas
- Clientes
- Permissões
- Histórico
- Eventos
- Documentos
- Auditoria
- API

Nunca terá interface.

Nunca terá ecrãs.

É apenas inteligência.

---

# 2. ATLAS

É o cérebro.

Comunica com o utilizador.

Compreende linguagem natural.

Conhece todo o sistema.

Ajuda.

Explica.

Executa tarefas.

Sugere melhorias.

Aprende.
