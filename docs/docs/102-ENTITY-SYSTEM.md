# ENTITY SYSTEM

## Regra Nº1

Tudo no RPG OS é uma Entidade.

Não interessa o que é.

Um Cliente é uma entidade.

Uma Empresa é uma entidade.

Uma Obra é uma entidade.

Uma Casa é uma entidade.

Um Técnico é uma entidade.

Um Equipamento é uma entidade.

Um Documento é uma entidade.

Uma Conversa é uma entidade.

Uma IA é uma entidade.

Tudo.

---

## Todas as entidades possuem

ID Global

Nome

Descrição

Data de criação

Data de atualização

Criado por

Última alteração

Estado

Permissões

Histórico

Anexos

Etiquetas

Relacionamentos

---

## O utilizador nunca deverá repetir informação.

Se um Cliente já existe...

Nunca volta a ser criado.

Apenas relacionado.

---

## Toda a informação pertence ao grafo.

Não existem tabelas isoladas.

Existe conhecimento ligado.

## Filosofia

O RPG OS não guarda ficheiros.

O RPG OS guarda conhecimento.

Os ficheiros são apenas parte desse conhecimento.
