# RPG OS CORE

## O Core é o coração do RPG OS.

Nada comunica diretamente.

Tudo comunica através do Core.

---

## O Core conhece tudo.

Clientes.

Empresas.

Utilizadores.

Permissões.

Ficheiros.

Mensagens.

Obras.

Imóveis.

Equipamentos.

Produtos.

Documentos.

Eventos.

Notificações.

Inteligência Artificial.

---

## O Core não pertence a nenhum módulo.

Todos os módulos pertencem ao Core.

---

## Um cliente criado no CRM é automaticamente conhecido por:

- Agenda
- Obras
- Financeiro
- IA
- Marketplace
- Analytics
- Documentos
- Chat
- API

Sem duplicação.

Sem sincronização.

Sem importações.

Existe apenas uma entidade.

---

## O Core nunca deverá conhecer interfaces.

Nunca deverá conhecer React.

Nunca deverá conhecer Flutter.

Nunca deverá conhecer Web.

Nunca deverá conhecer Mobile.

O Core apenas conhece informação.

---

## O Core deverá funcionar mesmo que todas as aplicações desapareçam.

Porque ele é o sistema.

As aplicações são apenas janelas.

---

## Tudo é uma entidade.

Tudo tem um ID.

Tudo tem histórico.

Tudo tem permissões.

Tudo tem proprietário.

Tudo tem auditoria.

Tudo tem versões.

Nada desaparece.

Apenas muda de estado.
